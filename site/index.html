grepless

A code map and a pre-tool hook for AI coding agents. A one-line tag above each block of code says what the block is for; a tool builds a map from the tags and the code; the agent asks the map, a round of questions per call, instead of searching with grep; and a hook refuses grep, cat and sed on the code. For Claude Code, OpenAI Codex, Cursor, GitHub Copilot and Gemini CLI.

What was measured

  • In 113 Claude Code sessions (26,007 calls, 10.7 billion tokens), 98.7% of the tokens were context the model had already been sent; the agents' own output was 0.3%. At list prices, re-reading was 59.5% of the cost.
  • The model replied three times slower with 700k to 900k tokens of context than with under 100k; among short replies alone, about 1.8 times slower.
  • Half of what 23 agents re-read on one day was code they had looked up with grep, sed and cat, or whole files read to find one thing.
  • With instructions alone, the median session sent 10% of its code reads through the map; with the hook, 85% (four sessions, different tasks, other changes the same day: an observation, not an experiment).
  • Replaying the first 532 calls of one session, with only the affected tests run and reads in rounds, gave 33% to 43% fewer tokens; with one session per change as well, 77% to 81% fewer (estimates).

Quick start

# the tool into tools/, then init: the areas, and the AGENTS.md text
curl -fsSL https://raw.githubusercontent.com/mars1571/grepless/main/install.sh | sh
python3 tools/map.py build                 # after tagging: writes the map
python3 tools/map-guard.py install claude  # or codex, cursor, copilot, gemini
python3 tools/map.py check                 # in CI

Python, Node, Go and Rust versions give the same answers; the compiled ones run the hook in about 3 ms per tool call. Setup per agent, tagging, and every command: in the README.
